# 保育×AI ノベルゲーム 実装版（素材組み込み開始版）

## 起動
このフォルダでHTTPサーバーを起動してください。

```bash
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開きます。

## 構造
- `public/assets/` : 提供された実在素材のみ。ファイル名は変更・複製していません。
- `src/assets.js` : 実在素材の共通参照レジストリ
- `src/scenes.js` : 場面①〜⑦＋エンディングのデータ
- `src/audio.js` : BGM / SE管理
- `src/main.js` : 画面描画、選択履歴、AI UI、進行制御
- `src/styles.css` : スマホ優先の画面レイアウト

## 内部ID
表示番号と内部IDを一致させ、`scene01-*`〜`scene07-*`、`ending-*` で管理しています。

## ローカルでの確認方法

Windowsでは、今回追加した `start-local.bat` をダブルクリックしてください。
自動的に簡易Webサーバーを起動し、`http://localhost:8000/` を開きます。

手動の場合は、ゲームのルートフォルダで次を実行します。

`python -m http.server 8000`

その後、ブラウザで `http://localhost:8000/` を開いてください。

## 開発用の場面選択
確認作業をしやすくするため、URL末尾に `?dev=1` を付けると
「場面①〜⑦／エンディング」の開始位置を選べる開発用メニューが表示されます。

例：
`http://localhost:8000/?dev=1`

GitHub Pagesでも同様に、
`https://ユーザー名.github.io/リポジトリ名/?dev=1`
で利用できます。

通常URLでは場面選択は表示されず、場面①から順に進むため、
完成版のプレイ動作には影響しません。
