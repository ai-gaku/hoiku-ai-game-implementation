# 保育×AI ノベルゲーム 実装版（素材組み込み開始版）

## 起動
このフォルダでHTTPサーバーを起動してください。

```bash
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開きます。

## 構造
- `public/assets/` : 提供された実在素材のみ。ファイル名は変更・複製していません。
- `src/assets.js` : 実在素材の共通参照レジストリ
- `src/scenes.js` : 場面①〜⑦＋エンディングのデータ
- `src/audio.js` : BGM / SE管理
- `src/main.js` : 画面描画、選択履歴、AI UI、進行制御
- `src/styles.css` : スマホ優先の画面レイアウト

## 内部ID
表示番号と内部IDを一致させ、`scene01-*`〜`scene07-*`、`ending-*` で管理しています。

## 現時点の位置づけ
素材ZIPにはマスター進行表そのものは含まれていなかったため、本文は直近まで合意していたプロトタイプ内容を基に組み込んでいます。完成版の文言・分岐をマスター進行表と完全一致させるには、その進行表のファイルまたは本文が必要です。


## GitHub Pages 用修正
`src/assets.js` のアセット基準パスを `/public/assets` から `./public/assets` に変更しました。GitHub Pages ではリポジトリ名がURLの途中に入るため、先頭 `/` の絶対パスだと画像・音声がドメイン直下を参照して404になります。

## 2026-08-28 UI / 音響調整
- AI画面を「プロンプト表示 → AIで整理する → 処理中アニメーション → 完了SE → 結果表示」に変更
- AI処理完了までは通常の「次へ」を表示しない
- 朝BGMは場面①のみ。場面②開始時にフェードアウト
- 場面②〜⑥は原則BGMなし
- 夕方BGMは場面⑦からエンディング終盤まで。最終画面でフェードアウト
- キャラクター画像の max-height 制限を外し、画像枠外は visual-stage の overflow:hidden でクリップ
- キャラクター位置は `p(asset, x, y, w)` で指定可能
- URL末尾に `?debug=1` を付けると、各立ち絵に現在の x / y / w を表示
